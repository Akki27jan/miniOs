============================================================
                  LarpOS Command Reference
============================================================

General Commands:
  larp          - Displays this comprehensive command reference.
  clear         - Clears the terminal screen.
  quit / exit   - Exits the MiniOS shell.

  system        - Reads from the /proc filesystem to display 
                  current system uptime, idle time, and memory 
                  statistics (MemTotal, MemFree).

  run <program> - Forks a new child process and uses execvp() to 
                    execute a standard Linux program (like 'ls' or 
                    'date') without crashing the main shell. The 
                    parent process waits for the child to finish 
                    using waitpid().
  
  submit <job>  - Submits a simulated task to a background worker.
                  The worker process uses a pipe to send the 
                  completion status back to the main MiniOS shell.
  jobs          - Lists the history of recently completed jobs
                  submitted during this session.
============================================================
